# 線徑 × 安培容量 × 無熔絲開關 選用工具

互動式網頁：<https://shunkai-lin.github.io/tw-wire-nfb-selector/>

依台灣《用戶用電設備裝置規則》（114.05.09 修正版）與華新麗華、大同、太平洋電線電纜型錄，快速查詢四種低壓導線的安培容量與可配用的無熔絲開關（NFB）額定：

| 絕緣種類 | 規則表 25-1 最高容許溫度 | 廠商資料 |
|---|---|---|
| PVC | 60℃ | 華新 IV 電線、太平洋 PVC 電纜 |
| XLPE 交連 PE | 90℃ | 華新、大同、太平洋 XLPE-PVC 電纜 |
| 105℃ PVC | 未列入（工具暫以 90℃ 欄計） | 華新 105℃ PVC 軟電線 |
| 海巴龍 Hypalon（氯磺化聚乙烯） | 90℃ | 華新海帕龍引出線 |

## 功能

- **由 NFB 反查線徑**：輸入開關額定，列出四種導線在指定配線方式、同管條數、周溫下的最小線徑。
- **依條件查安培容量**：列出各線徑的規則值、修正後值、NFB 上限，以及華新型錄換算值。
- **發電機回路選用**：輸入 kW 與電壓系統（220V 3φ3W／380/220V 3φ4W），算出額定電流、控制盤主開關（MCCB 或 ACB＋Ir 設定）、ATS 額定與發電機→控制盤→ATS 的並聯線徑，並附 30～750kW 一覽表。
- **發電機機型（大同／中興）**：大同 TPU、中興 CH 柴油發電機組 30～750kW 型號、kVA、kW、引擎型號，可篩選並帶入回路計算。
- **四種導線對照總表**、**電纜廠商型錄原始值**（含周溫／多條換算係數）、**絕緣材料說明**、**規則重點與來源**。

## 計算依據

- 安培容量：第 25 條；表 25-2～25-4（金屬導線管，60／75／90℃）、表 25-5（PVC 管，60℃）、表 362-1／362-2（多芯電纜於電纜架／空氣中）。
- 同管導線數修正：表 25-6（10 條以上，或表 362 的 4 條以上）；周溫修正：表 25-7。
- NFB 選用：第 79 條。額定 ≤ 導線安培容量；2.0mm ≤15A、3.5mm² ≤20A、5.5mm² ≤30A。
- 標準額定序列採常見市售 NFB 額定（第 74 條：以製造廠型式試驗為準）。
- 發電機回路：出線導線安培容量 ≥ 115% 額定電流（NEC 445.13，台灣規則對應條文待確認）；主開關取 ≥ 115% Iₙ 之標準額定，超過 800A 用 ACB；導線同時須符合第 79 條。
- 華新參考值 = 型錄電線管佈設 Iₙ × f₁（周溫，取不低於實際溫度之欄）× f₂（同管條數，3 條以下取 2～3 條係數）。
